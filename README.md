# Rentora - Equipment Rental Platform

## Purpose
Rentora is an equipment rental marketplace that connects customers with verified equipment owners in Bangladesh. The client is the Next.js web app for browsing and booking machinery, managing rentals and listings, and administering the platform.

## Live URL
https://rentora-client-orcin.vercel.app

## Key Features

- Home page with animated categories, featured equipment, reviews, and how-it-works sections.
- All Equipment page with server-side search, category/rental-type/price/availability filters, sorting.
- Equipment details with favorites, booking modal, live ৳ BDT price calculation, and Stripe Checkout.
- Customer dashboard: my rentals, favorites, profile.
- Owner dashboard: analytics, add equipment, my equipment, incoming rentals, profile.
- Admin dashboard: analytics, all users, equipment moderation, all rentals, profile.
